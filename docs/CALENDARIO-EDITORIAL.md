# Calendario editorial del blog — Granalva

El blog se activará en la fase 5, con publicación desde `/admin`. Cada artículo debe:

- responder una **duda real** de clientes, que se puede detectar en llamadas, correos, preguntas de Google Business Profile o consultas de Search Console;
- aportar **experiencia propia** de Granalva: procesos, errores habituales y criterios;
- **no inventar** cifras, clientes ni resultados;
- enlazar **una página comercial principal** con un texto de anclaje descriptivo y, como mucho, otra secundaria;
- tener autor real, fecha, imagen propia cuando exista y su propio title y description;
- no repetir la intención de una página de servicio (el artículo informa; la página de servicio vende).

Ritmo recomendado: **uno o dos artículos al mes**, sostenibles y revisados. No se publican series generadas automáticamente.

## Cómo medir cada artículo

Tres meses después de publicarlo, revisar en Search Console:

- impresiones y clics;
- consultas reales por las que aparece;
- clics hacia la página comercial enlazada.

Si el artículo no recibe impresiones, se revisa el enfoque: no se publica otro artículo casi idéntico.
